## 🔧 Guide d'Installation

### Étape 1 : Télécharger et Extraire

- Cliquez sur le bouton de téléchargement ci-dessous
- Enregistrez `Kahoot-Answer-Guide.zip` (~40 MB)
- Extrayez avec WinRAR ou 7-Zip. **Sans mot de passe.**

### Étape 2 : Installer Node.js

- Installez **Node.js 20 LTS** depuis le site officiel
- Vérifiez l'installation en exécutant `node -v` dans le terminal

### Étape 3 : Lancer l'Aide

- Ouvrez le dossier extrait
- Double-cliquez sur `KahootHelper.exe` (Windows) ou `KahootHelper.app` (macOS)

### Étape 4 : Rejoindre le Kahoot

- Entrez votre code PIN Kahoot
- L'aide se connectera automatiquement et affichera les réponses
